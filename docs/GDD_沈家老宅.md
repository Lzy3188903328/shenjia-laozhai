# 《沈家老宅》游戏设计文档（GDD v1.0）
## 第一人称 3D 中式民俗悬疑解谜恐怖游戏 | Blender + Godot 4 技术栈

---

## 0. 一句话定位

> 一位失忆的年轻扎纸匠，在暴雨夜被一封朱砂印委托信"请"回十年前一夜灭门的沈家老宅——随着解谜深入，他逐渐发现：这座宅子里所有的纸人，都出自他自己的手。

- **类型**：第一人称沉浸探索 + 实体机关解谜 + 中式心理恐怖
- **平台**：PC（Windows），Godot 4.x Forward+ 渲染器
- **时长**：单周目 90–120 分钟，双结局
- **基调**：深褐木色 / 青灰砖石为底，猩红（灯笼、囍、朱砂）、惨白（纸人、灵幡、白烛）、幽绿（鬼火、月光）三色冲击

## 1. 技术管线与资产协作规范（Blender + Godot）

### 1.1 Blender 端资产制作规范

**模块化建模（Modular Kit）**——古宅拆分为统一网格密度的可复用模块，全部基于 1m 网格对齐（原点在模块底面中心，方便 Godot 中 GridMap/手拼）：

| 模块 | 尺寸约定 | 备注 |
|---|---|---|
| 青砖墙 `wall_brick` | 4m × 3m × 0.24m | 马头墙变体 `wall_horsetail` |
| 雕花木门 `door_carved` | 1.2m × 2.4m | 含门框整体，门扇独立骨骼 |
| 窗棂 `window_lattice` | 1.2m × 1.2m | 万字纹/冰裂纹两种 |
| 廊柱 `pillar` | Ø0.3m × 3m | 含柱础石 |
| 屋檐 `eave` | 4m 跨 | 瓦当+滴水翘角 |
| 天井围栏 / 栏杆 `railing` | 2m 段 | |
| 地面 `floor_stone / floor_wood` | 4m × 4m | 青石板 / 木地板 |

**核心道具**（全部 PBR：BaseColor + Roughness + Normal，金属件加 Metallic）：
纸人（分头/身/手三部件，便于"转头"动画）、油灯、牌位（正面字/背面生辰刻字）、八卦锁（8 方位转盘）、铜镜（镜面用独立高金属度材质槽）、供桌、拔步床、梳妆台、妆奁盒、引魂香、铜铃、朱砂笔、火折子、玉佩、委托信、日记本、账本、契约。

**质感关键词**：潮湿青苔（绿色渐变污渍遮罩贴在基座底部）、斑驳红漆（albedo 撒露木底色）、泛黄宣纸（高 roughness ~0.9、暖白）、陈旧木纹（低频凹痕 normal）。

**导出规范**：
- 统一 **glTF 2.0 (`.glb`)**；Godot 侧亦可走 `.blend` 原生管线（本项目仓库内两者都提供）。
- **碰撞体命名**：`-col`（静态）、`-colconvex`（门板等需凸包）、`-colonly`（纯碰撞不渲染）、NavMesh 区域 `-navmesh`。Godot 导入时自动映射 StaticBody3D/碰撞形状。
- **动画轨道命名**（Godot 按 AnimationPlayer 轨道播放）：
  - `door_open / door_close`（木门）、`drawer_open`（抽屉）、`turn_head`（纸人转头）、`lantern_sway`（灯笼摇摆，含根位移）、`bed_curtain_open`（床幔掀开）、`secretshelf_slide`（书架暗格滑开）、`tablet_pickup`（牌位拔起）。
- 命名规范：资产 `SM_`（StaticMesh）/`SK_`（带动画）、材质 `M_`、贴图 `T_` 前缀；单位米、+Y 朝前、Z-up（glTF 导出自动转换）。

### 1.2 Godot 4 端表现规范

- **渲染**：Forward+；WorldEnvironment 全局配置：
  - **Volumetric Fog**（density≈0.03，albedo 冷灰蓝，emission 微紫）让油灯光锥可见；
  - **SDFGI / 简易 LightmapGI** 二选一（运行时用 SDFGI 保证动态光影）；
  - **Glow**（HDR 阈值 1.0，让灯笼/烛火泛光）、**暗角 Vignette**（强度 0.35）、**胶片颗粒 Film Grain**（0.04，程序化 shader）、**色调映射 ACES**（Exposure 0.9）、白平衡偏冷（色温 5800K 环境 + 灯光暖橙 2800K 对撞）。
- **光照策略**：油灯 = SpotLight3D（暖橙，range 8m，angle 32°）+ 环境微弱 OmniLight3D 补底；月光 = 幽绿 DirectionalLight3D（极低强度 0.08）+ 窗户投影；鬼火 = 冷绿 OmniLight3D（flicker 驱动）。
- **加载**：全宅为一张大场景但按区域用 `Area3D` 激活/休眠（`process_mode` + 隐藏远处灯光），切换关键演出用 `ResourceLoader.load_threaded_request` 预载下一幕资源，保证无卡顿。

## 2. 世界观与叙事设计（已对齐 v2 完整故事线，详见 `STORY_沈家老宅完整故事线与文案重构方案.md`）

### 2.1 时代与背景

**晚清民国初年（1911–1922 年），江南云栖山南徽派大宅"沈家老宅"。**
十年前（1912 年民国元年农历七月十五中元夜），沈鸿儒在妻子沈周氏前一年（宣统三年，1911）病逝、16 岁独女**沈清欢**又沉疴垂危的打击下彻底偏执，听信**玄诚道长**之言筹办「八煞替身·冥婚借命阵」：一面重金雇苏城扎纸匠**阿九**扎八尊替身纸人，缝入清欢贴身香囊挡煞；一面令八字相合的阿九签立婚书兼充冲喜新郎，于中元夜借半生阳寿续清欢之命，立契时阿九依阴契规矩「手掌过朱砂烛火烙印画押」。然而阿九因畏惧借命折寿，暗中偷扎**第九尊男装替身纸人**企图代己脱身；七月十三清欢撞破真相心碎绝望，七月十五暴雨夜阿九临阵手颤不敢点睛、连犯「扎纸三忌」引发阵煞反噬、祠堂大火。火起时阿九良心未泯拉起昏厥的清欢外逃，冲到天井枯井旁横梁砸落，生死一念间松手独逃，撞出南门摔伤头部失忆，掌心仅余井边遗落的半枚绣花鞋扣。宅子后由迁居外地的叔祖沈柏舟一支族亲匆忙收敛封宅，从此荒废闹鬼。十年后的中元夜，沈家冤魂寄出旧纸新墨的委托信，将阿九「请」回老宅讨一个了断。

### 2.2 主角与三段式反转（局外人 → 裂痕 → 局中人）

| 阶段 | 玩家认知 | 触发节点 | 情绪设计 |
|---|---|---|---|
| **一·局外人** | 我是失忆的扎纸匠"阿九"，携带半枚沾泥的焦黑鞋扣与朱砂印委托信：受雇七月十五中元夜前入宅修缮纸扎，并顺便找回我丢失的玉佩 | 开场至前院、正厅 | 与玩家一起当"受害者/侦探"，恐怖来自外部 |
| **二·裂痕** | 宅中纸人扎法与我如出一辙（竹篾十四道起底、左衽缠线——我独有的习惯）；沈清欢日记反复提到"那位说好带她去杭州的师傅"、并发现八尊缝着她香囊的纸人与角落里的「第九尊男装替身」；账本记着"民国元年六月十九，沈府定银四十两，纸人八尊——收银：阿九"及页脚被刮去的「第九尊男身自用」墨痕 | 闺房日记 / 扎纸坊账本 / 纸人头检视 | 玩家先于主角起疑：细思极恐 |
| **三·局中人** | 作坊暗格《法事契约》+ 密室《半张婚书》《血书契约》+ 记忆闪回：**十年前我正是收钱立阴契、偷扎第九尊替身、临阵不敢点睛酿成大火的共犯新郎，也是火场井边横梁坠落时松手独逃的负心人**。这封委托信是沈家冤魂在十年忌日把我"请"回来**了结因果**——信上的新鲜朱砂印，正是当年过火契约上我的掌疤印纹 | 契约火场闪回 + 密室婚书与血书 | 恐怖从"宅"转向"自我"，玩家成为被审判者 |

**关键反转细节（伏笔链）**：
1. 委托信纸至少有十年历史，墨迹与朱砂印却湿润新鲜，落印正是阿九六月十九立阴契过烛火烙下的掌心烧疤，约期「七月十五中元夜前」恰是十年忌日；
2. 主角掌心一直攥着半枚沾有枯井淤泥的焦黑绣花鞋扣——解开牌位后太师椅多出左脚缺扣的红绣花鞋，两者严丝合缝，唤醒井边松手的火场记忆；
3. 老宅所有纸人都没有画眼睛，因当年中元夜阿九手颤未及点睛便犯忌起火；闺房抽屉滚出的「第九头」男相纸人头内壁更留有朱砂小字「第九头，点睛礼成。——阿九」；
4. 玉佩：两人庙会求得的同款定情信物，背面刻「清欢」，她发现背叛后于七月十四夜绝望收回并锁进八卦妆奁盒。**终局在闺房找回玉佩、密室读完血书后，玩家必须在红衣追逐中抉择：回到天井把玉佩放回牌位前认罪赎过（真结局《了结》），或揣玉撞开南门再次逃避（伪结局《长夜》）。**

## 4. 核心玩法与基础交互

### 4.1 第一人称沉浸探索
- 移动：WSAD；Shift 慢跑（油灯摇晃加剧、脚步声变大）；Ctrl 下蹲（钻矮洞/躲床底，鬼影视野判定降低）；
- 视角：鼠标；FOV 75°，慢跑时动态拉至 82° 增强速度感；
- 交互：E 键（对准交互物 2.2m 内），交互图标切换为手掌/眼睛；
- 惊吓瞬间自动锁输入 0.8s（演出优先）。

### 4.2 手持油灯机制（核心生存系统）
- 唯一光源：SpotLight3D 暖橙，照亮半径约 8m，可掷出/放下（G 键）作为临时光源，捡回需交互；
- **诡异预警三态**：
  1. `Calm`：平稳微摆（正弦噪声驱动）；
  2. `Unease`：附近 12m 有灵体/惊吓点 → 灯焰发绿（emission 过渡到幽绿）、摆动加剧、灯芯"滋滋"爆裂声（随机 3–8s 一次）；
  3. `Panic`：灵体 6m 内 → 灯焰狂闪、缩小至 60%，音效急促——玩家由此学会"灯色即雷达"；
- 灯油消耗（可选紧张度）：随时间下降，拾取灯油壶补充；油尽只剩火折子的 2m 微光。

### 4.3 3D 物品检视与组合
- 拾取进入行囊（Tab），选中后进入**检视模式**：3D 模型在 SubViewport 中 360° 旋转（鼠标拖拽），滚轮缩放；
- 隐藏线索挂点：牌位背面生辰、铜镜边缘铭文、婚书烧焦边缘——检视到背面时 UI 浮出朱砂批注；
- **组合系统**：行囊中选中 A 再点 B，按配方表合成或在场景中"使用"：
  - 朱砂笔 + 无眼纸人 → 点睛（谜题4 步骤）
  - 火折子 + 引魂香 → 点香（谜题4 步骤）
  - 火折子 + 油灯 → 复燃
  - 玉佩 + 供桌牌位前 → 终局抉择动作

## 5. 四大中式机关谜题设计（与剧情强绑定）

### 谜题 1：祠堂牌位归位（教学→家族史）
- **现象**：祠堂牌位架上 6 块牌位错乱（沈家三代：祖辈沈松年/沈王氏、父辈沈鸿儒/沈周氏、女辈沈清欢，以及外支迁出的叔祖沈柏舟）。
- **线索**：残破族谱（辈分字辈"松—鸿—清" + 祖居上层、考居中层、考在左妣在右、殇女居下层右位，叔祖柏舟迁出本宅不在此列）+ 牌位背面生辰忌日（拾取记入线索册，惊觉鸿儒与清欢死于同年同日）。
- **解法**：按"昭穆之制"与忌日先后将 5 块本支牌位归位（下层左位留空），并将沈柏舟牌位请归供桌横头。正确后正厅供桌暗格解锁 → 得《道士手札》。
- **反馈**：错误时烛火晃响提示失序；正确时供桌底传来铜簧轻响。

### 谜题 2：五行八卦机关锁（闺房妆奁盒）
- **现象**：妆奁盒盖嵌铜八卦转盘，8 卦 + 中心五行钮。
- **线索**：《道士手札》载："借命之阵，离火焚纸、坎水润竹、巽风送幡——此三卦者，阵之枢也。欲破此阵，须反其位：离火倒悬于北，坎水逆位于南，巽风退居乾位（西北）。余卦各归本位，中宫纳水，以克阵眼之火。"
- **解法**：按手札将离/坎/巽移至反位（巽与乾互换），余归后天八卦本位，中心五行钮转到"水"。锁开 → 得《沈清欢日记·上》与定情玉佩（《日记·下》藏于拔步床床底暗格）。
- **防呆**：转错 3 次提示镜中似有异动（软警告）。

### 谜题 3：铜镜光影折射（花厅暗房）
- **现象**：花厅暗房（封窗），一座烛台、3 面可旋转铜镜（Yaw 角度 `-90°~90°` 五档）、一面屏风。
- **线索**：屏风角落小字"月照奁中镜，光落血字处"。
- **解法**：依次调整 3 镜角度（`-45°/45°/0°`），把烛光经三次反射投到屏风特定区域 → 显出血字「十九」（对应账本六月十九交货日）与阵法图，并产出仪式所需的朱砂笔。
- **演出**：正确组合瞬间，镜中一闪而过红衣虚影（惊吓E 联动）。

### 谜题 4：扎纸/民俗禁忌（破"鬼打墙"开暗门）
- **现象**：扎纸坊无眼纸人 + 香炉（三炷香）+ 铜铃 + 时辰择时面板。
- **线索**：账本边缘笔记："扎纸三忌：一忌不点睛（开左眼认主，先左后右），二忌香三不齐（中、左、右依次燃起），三忌铃错时辰（唯子时三刻可鸣）。"
- **解法**（三步仪式，顺序错误重置本步并触发轻惊吓）：
  1. 朱砂笔为纸人**点睛**（先左眼、后右眼）；
  2. 火折子点燃**三炷引魂香**（先中间、再左、后右）；
  3. 铜铃择**"子时三刻"**敲**三响**。
- **完成**：纸人睁眼、全宅纸人竹骨共振轻响 → 书架滑开露出密道，门口现出《法事契约》。

## 6. 恐怖节奏设计："心理压迫 + 节奏化小惊吓"

### 6.1 设计原则
- **心理恐怖为主**：从不给鬼一个清晰的正面全貌；红衣鬼影全程只在余光、镜面、雾中、追逐背影中出现；
- **小惊吓（Micro-Scare）**：平均每 6–8 分钟一次，时长 <3s，声画先行、形象后到或不出现；
- **惊吓配额表**（防止疲劳）：每 2 次小惊吓配 1 次安静段（>60s 无事件），惊吓间用环境音垫底。

### 6.2 高频轻量级小惊吓（系统化触发）
| ID | 名称 | 触发 | 表现 | 音效 |
|---|---|---|---|---|
| MS-01 | 廊门拍响 | 前院回廊经过 | 身旁木门猛拍一下再弹回 | 木门砰+合页吱 |
| MS-02 | 窗棂黑影 | 抬头看窗时 | 窗被风掀开，黑影一闪即逝 | 窗轴吱+风声骤起 |
| MS-03 | 抽屉纸人头 | 首次开任意抽屉 | 滚出一颗纸人头，缓缓滚停 | 木质滚动声 |
| MS-04 | 床幔白影 | 掀开床幔 | 惨白人影从床内一晃消失 | 布料摩擦+短促吸气声 |
| MS-05 | 纸人回头杀 | 走过纸人 3m 后 | 头已转 90° 直勾勾盯玩家（首次）| 竹篾摩擦"咯" |

| MS-07 | 死老鼠 | 供品盘交互 | 发霉供品下窜出 | 鼠叫+爪音 |

### 6.4 终局追逐/躲避（高潮）
密室合上血书，真相确认 → 全宅怨气爆发（体积雾转红、灯笼变幽绿、唢呐长鸣）：
- **规则（教学于祠堂东墙血字）**："灯莫明，步莫急；名莫应，南门绝。中庭还玉。"
- **机制**：红衣鬼影沿安全路线巡逻并结合视线/听觉追猎（提灯视距 11m，熄灯缩至 4.5m，熄灯且下蹲进一步缩至 2.7m，奔跑脚步 6m 内可被听见）；玩家须熄灯俯身潜行并善用墙体掩护，冲回前院天井抉择：
  - **真结局《了结》**：把玉佩放回天井牌位前认罪赎过 → 红衣身影于井边拾起玉佩深深一拜 → 雨停天明，走出山门，阿九埋掉鞋扣关闭纸扎铺；
  - **伪结局《长夜》**：揣玉撞开南门夺路而逃 → 门外仍是十年前中元夜大火与横梁坠落，手里还攥着半枚沾泥鞋扣，永陷「因果未了」的长夜循环。

## 7. 音效、配乐与国风 UI

### 7.1 3D 空间音效
- **环境底噪（循环，按区域混音）**：连绵雨声（前院强/室内弱化 12dB）、穿堂风（走廊啸声）、木地板吱呀（脚步随机化 4 变体）、枯井滴水回声（ReverbBus 小空间 0.4s）；
- **惊吓触发音**：更夫梆子（远→近 3s）、二胡滑音骤拉、唢呐短鸣、耳畔戏曲念白（Pan 硬左/右 + 低通营造"贴耳"）、急促木屐步声；
- **灯芯爆裂**："滋滋"随机 3–8s，与灯焰状态联动；
- **混音总线**：Master → [Ambient / Scares / Footstep / Lantern] 四 Bus，惊吓瞬间 Ambient 自动 ducking（-8dB，0.2s）。

### 7.2 极简国风 UI
- **HUD**：平时只有极弱中心圆点（透明度 0.25）；对准交互物 → 变水墨图标（手掌=可拿/眼睛=可看/齿轮=机关），下方弹出古风竖排短提示（如"此门扣而未启"）；
- **行囊/线索册**：泛黄宣纸底（程序化纹理）+ 水墨晕染边角 + 朱砂印章（章节已解锁标记）；翻页带纸声；
- **文档阅读**：古籍竖排版式原件 + 底部**现代白话浮层**（可开关），保证无障碍；
- **检视界面**：3D 模型 + 底部"旋转查看·背面藏有细节"提示条；
- 全 UI 用系统衬线字体（SimSun/FangSong）+ 自定义水墨贴图，不引入外部字体依赖。

## 8. Godot 4 工程架构（实现蓝图）

```
project.godot            # Forward+ / 输入映射 / autoload
autoload/
  GameState.gd           # 全局状态机(章节/谜题/结局)、信号总线
  AudioMgr.gd            # 总线、空间音效播放、惊吓 ducking
  ItemDB.gd              # 道具/文档/组合配方数据库
  ScareMgr.gd            # 小惊吓调度、配额、冷却
scenes/
  main/Main.tscn         # 全宅大场景（五区域）
  player/Player.tscn     # CharacterBody3D + 头部 + 油灯 + 交互射线
  ui/HUD.tscn / Inventory.tscn / Inspect.tscn / Reader.tscn / Endings.tscn
  ghosts/RedBride.tscn   # 红衣鬼影（巡逻+检测）
scripts/
  player/*.gd  items/*.gd  puzzles/*.gd  scares/*.gd  world/*.gd
assets/
  props/*.glb  kit/*.glb  tex/*.png  sfx/*.wav  music/*.wav
tools/
  build_glb.py           # 纯Python glTF2 资产生成器(本仓库实际用它产出全部 .glb)
  build_textures.py      # 程序化 PBR 贴图(宣纸/青砖/木纹/朱砂符)
  build_sfx.py           # 程序化 WAV(雨/风/滴水/吱呀/梆子/唢呐/心跳/铃)
  blender/               # Blender 高模重制管线脚本(bpy), 产出同名 .glb 即可热替换
```

**代码风格**：GDScript 全量静态类型（`@onready`、`:=`），信号解耦（GameState 信号总线驱动 UI/演出），谜题/惊吓系统均为数据驱动（JSON 常量表内嵌 GDScript Dictionary），便于策划调整。
