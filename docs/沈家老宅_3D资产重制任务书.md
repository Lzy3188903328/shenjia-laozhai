# 《沈家老宅》全套 3D 资产重制任务书

请在现有 Godot 4.7 项目《沈家老宅》中，使用 Blender 重制全部 **50 个 GLB 模型**，包括 12 个建筑模块和 38 个道具与角色。项目目录为 `D:\Downloads\godot3d项目`。交付可以放进游戏运行的模型、贴图、可编辑 Blender 源文件和导出脚本。最终效果以 **Godot 第一人称画面**验收。

开始前先读 `project.godot`、`scripts/world/WorldBuilder.gd`、`tools/blender/README.md` 和相关交互脚本，再检查 `assets/kit/` 与 `assets/props/` 中的现有 GLB。**实际运行的 GLB 和当前 Godot 脚本是尺寸、节点、碰撞和动画的依据。** 沿用现有主线、谜题解法、操作方式和角色通行尺度。需要调整光照或道具摆放时，先在样板场景中验证效果。

## 一、美术方向

做成一座**写实比例、适度风格化的江南深山徽派老宅**。建筑和器物体现晚清民初的做工。青砖、灰瓦、褪色朱漆、旧铜、竹篾和宣纸是主要材质。玩家靠近时，要看得出物件由什么做成、怎么装起来、哪里被用旧了。

- **建筑靠构造出效果。** 天井四周要看得出柱础、梁枋、檐口、门槛和窗棂的进退关系。从南门望向正厅，能辨认屋顶轮廓和进门路线。
- **磨损跟着使用痕迹走。** 门把手和妆奁锁扣磨亮，门槛中间磨平，墙脚受潮，瓦下有雨痕，长期未触碰的凹处积灰。相邻物件的磨损程度可以不同。
- **纸扎保留薄、脆的感觉。** 衣摆有纸折和接缝，内侧能看到少量竹篾，脸以裱纸和手绘五官表现。纸人远看近似站着的人，走近才发现手指和眼睛的做法很不自然。
- **让光照出材料。** 油灯的亮点集中在火苗，暖光照出纸纤维和竹骨。室外保留冷灰雨夜，室内用少量暖光引导视线。雾、暗角和颗粒调到还能看清门、台阶和解谜物件的程度。

## 二、先做样板，再量产

先重制**手持油灯、正厅纸人、正厅供桌、门、青砖墙和木地板**，把它们放进同一段可玩的场景。验收路线是**南门出生点 → 穿过天井 → 打开正厅门 → 走到供桌前**。

在这段路线里交付四组同机位的前后对比图。

1. 天井远看正厅，能辨认门、回廊、屋檐和导向灯光。
2. 门前伸手可及的距离，看得出门框、门樘、门板和金属件。
3. 正厅从入口看供桌和两尊纸人，能清楚看出主次。
4. 第一人称近看油灯和纸人脸，检查火苗、纸面、模型穿插和视野遮挡。

以这组实际游戏画面的颜色、材质、尺度和细节密度为标准，继续制作剩余资产。制作顺序为**建筑模块 → 关键解谜道具 → 各房间家具与小道具 → 红衣鬼影与终局画面**。

## 三、建筑模块（12 个）

以下文件均在 `assets/kit/`。模块要能在现有地图里反复拼接和缩放。实际走一遍转角、门洞和台阶，检查墙地交界与通行宽度。

| 文件 | 制作要求 |
|---|---|
| `wall_brick.glb` | 做出灰青砖的错缝和凹灰缝，墙脚有返潮、少量白霜和苔斑。用材质变化减轻重复感。保留墙段尺寸和拼接原点，确认门洞的可见范围与碰撞范围一致。 |
| `wall_wood.glb` | 做出木板、板缝、横档和边框。木纹沿板材走向，旧漆从边沿与接触处露出木底。 |
| `pillar.glb` | 做实柱础、木柱和柱头的连接。石柱础可有磕角，柱身有垂直木纹、开裂和漆面磨损。检查柱础外沿与现有通道的间距。 |
| `beam.glb` | 做清梁、枋和搭接端头，让梁柱连接有承托关系。雕饰集中在风格明确的部位，保留断面和长度基准。 |
| `roof_seg.glb` | 优先改善屋檐剪影。做瓦垄、滴水、檐板和从下方能看到的椽头。瓦片可有少量错落，模块两端拼接时瓦垄和檐线应连续。 |
| `door.glb` | 做出门框、双边门樘、厚门板、门钉、铜拉环和门槛。门扇绕合页开启。门框碰撞覆盖两侧和上方，门扇有独立、随动画移动的碰撞。 |
| `window.glb` | 做有厚度的木窗框和镂空窗棂。把榫接、破纸和旧漆放在近看能辨认的位置，从室内外都检查轮廓和材质。 |
| `railing.glb` | 做立柱、扶手、横档和镂空栏板。重复构件对齐，栏杆顶有长期接触造成的磨损。 |
| `floor_stone.glb` | 做大小有变化的石板、暗缝和湿润区。角色的行走碰撞面要平顺，水光集中在雨水积聚处。 |
| `floor_wood.glb` | 木板有不同长度、接缝、钉头和轻微凹凸。靠门和走道更磨亮，柜下更暗。关卡把地板拉伸到不同房间后，检查木纹和板宽。 |
| `step.glb` | 做石阶层次、微倒角、破角和踏面的磨亮区域。核对踏步尺寸，并用角色实际走过有台阶的入口。 |
| `plaque.glb` | 做旧木匾、边框和固定结构。保留 Godot 叠放 `Label3D` 的字面空间。这个模型也被复用作花厅屏风，两处都要验收。 |

## 六、Blender 与 Godot 技术要求

### 尺寸、朝向与枢轴

建模前记录旧模型的包围盒、底面原点、正面方向和枢轴。以米为单位，按 Godot 导入后的实际坐标校准。墙段和地面按现有 `WorldBuilder` 的缩放方式测试。模型升级后，门洞、台阶、柜子、暗道和物件摆放仍须对齐。

### 关键命名与动画

保留 GLB 文件名、运行时识别的根节点及子节点。下表列出了需要逐项验证的接口。

| 资产 | 节点或动画 |
|---|---|
| 门 | `DoorLeaf`、独立门扇碰撞、`door_open`、`door_close`。在 Godot 的碰撞调试视图中确认门樘、门楣和门扇使用独立碰撞。 |
| 手灯、挂灯 | 手灯的 `Flame` 网格，挂灯的 `Body` 摆动目标，`lantern_sway`。 |
| 纸人 | `Head`、`Face`、`turn_head`。`Face` 的 UV 对上有眼和无眼两套贴图，左右点睛位置可操作。 |
| 铜镜架 | `Mirror`，镜面朝向、轴心和交互挂载与原逻辑吻合。 |
| 香炉 | `IncenseMid`、`IncenseL`、`IncenseR`，以及对应的 `EmberMid`、`EmberL`、`EmberR`。 |
| 铜铃、妆奁、书架 | `Clapper` 与 `bell_ring`，`Lid` 与 `box_open`，`SecretPart` 与 `secretshelf_slide`。 |
| 供桌、床、牌位 | `Drawer` 与 `drawer_open`，`Curtain` 与 `bed_curtain_open`，`tablet_pickup`。 |

导出后在 Godot 场景树与 `AnimationPlayer` 中检查这些内容。在 Godot 运行场景后，验证脚本能找到对应节点，并播放完整动画。

### 碰撞与交互

可见网格和碰撞代理分开。沿用项目的 `-colonly` 等命名与实际导入设置，优先用简单代理。角色通行、准星交互和视线遮挡分别验收。特别检查门框、纸人眼睛、三炷香、铜镜、牌位架、抽屉和暗门。

### 贴图与材质

用可导出的 PBR 贴图表现木材、纸、陶、铜、石和布。Blender 中的程序纹理应烘焙或转成 glTF 能呈现的纹理和材质。建筑的重复材质集中复用，手灯、纸人脸和关键线索优先给更高的近看精度。核对 `assets/tex/` 里被脚本直接读取的贴图，例如纸人脸部的 `t_face_eyed.png`，检查替换贴图的 UV 和颜色空间。

### 性能预算

以**小道具 200–1,500 三角面、家具 1,000–5,000、近景核心道具 3,000–10,000**作为初始制作基线。重复建筑优先共用材质和贴图，细碎划痕、纤维和砖缝优先交给纹理。控制火苗、灯罩和薄纱的透明层数。在天井、正厅和追逐场景记录帧耗时、绘制调用和纹理显存，根据实测调整预算。

## 七、交付与验收

- **交付源文件和游戏资产。** 提供可编辑 `.blend`、贴图、可重复执行的 Blender 导出脚本和 50 个同名 `.glb`。资产清单标明每个模型的源文件、导出路径、碰撞和动画。使用外部素材时记录来源及授权。
- **分批导入。** 每批先导出到独立目录并验证，再替换正式资源。保留一份可回滚的旧资产。明确从新源码导出的入口，避免旧的 `tools/build_all.py` 重新生成时覆盖成品。
- **在实际游戏里验收。** 进入各区域检查比例、材质、灯光、碰撞和交互。实际验证开门、石阶通行、抛灯拾回、牌位归位、铜镜转动、点睛、上香、敲铃、书架滑开以及终局两条路线。运行现有 `smoke`、`playthrough`、`input_regression` 和 `windowed_check`。
- **提供前后对照。** 在相同机位和曝光下提供天井、正厅、祠堂、花厅、闺房、作坊和密室的 Godot 截图，再附手持油灯、纸人脸和关键谜题道具的近景。如果也调整了曝光或后处理，把最终灯光效果额外单独展示。汇报已替换的模型数量、实际验证结果和待处理的问题。

**完成标准是 50 个模型全部导入，并在现有游戏里正确工作。** 玩家从南门走到正厅时，应能从屋檐、木门、纸人和手里的灯认出这座宅子的年代、地方与用途。
